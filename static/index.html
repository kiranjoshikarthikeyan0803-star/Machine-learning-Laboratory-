How to Compile & Run This Project

Comprehensive guide for command-line execution and local setup

1. One-Click Quick Launch (Windows)

Simply double-click the included batch script in the project root directory:

run.bat

This automatically validates dependencies and opens the web application at http://localhost:8000.

2. Manual Installation via Pip

Open PowerShell or Command Prompt in the project folder and install dependencies:

pip install -r requirements.txt

3. Run the Web Application Server

Launch the FastAPI high-performance web server:

python app.py

Then open your browser to: http://localhost:8000

4. Standalone Model Training via CLI

Train and validate machine learning classifiers directly from the terminal:

python train_standalone.py --algorithm random_forest --split 0.25

Supported algorithms: random_forest, svm, knn, logistic_regression, gradient_boosting.

5. Standalone Image Inference via CLI

Run cancer diagnosis on any clinical image without opening the browser:

python predict_standalone.py --image static/samples/malignant_melanoma_01.png

6. In-App Interactive Code Playground

Click the Code Sandbox button in the top navigation bar. You can type Python code directly in the browser, execute it, and see console outputs immediately!
